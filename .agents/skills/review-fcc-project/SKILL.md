# Review an fCC Project

Goal: deepen understanding, not just hand over a better solution.

- Read the code plus `user-story.md` (or search the fCC repo). Passing tests is the baseline, not the bar.
- Find the project in `fcc-fedl-curriculum.md`; keep suggestions within what's been taught (RWD and JS certs are done). Anything beyond goes in a labeled **Look ahead**.
- Cover what matters: correctness, readability, idiomatic React/TS, beginner habits to fix early, edge cases, and what they did well. Separate real problems from style preferences; skip empty categories.
- Explain *why* in plain language with `file:line` refs and short before/after snippets. Encouraging, but honest.
- Don't edit the project unless asked.
